离线便携博客 · Windows 10 / 11 64 位

一、第一次使用
1. 将整个 ZIP 解压到 E:\PortableBlog，或任意有写入权限的本地目录。
   不要直接在压缩软件内运行，不要只复制启动文件。
2. 双击“启动博客.bat”（或 Start-Blog.bat）。保持黑色窗口开启。
3. 浏览器会自动打开。如没有打开，在浏览器输入 http://127.0.0.1:8765
4. 点击“管理后台”，设置至少 8 位密码。
5. 在“文章”中写文章、选类目、上传或选择附件，再保存为草稿或已发布。

二、功能
- 文本文章、草稿、发布、编辑、删除、标题和正文搜索。
- 图片、视频、音频、PDF 和 TXT 原文件存储，单文件最大 1GB。
- 图片与视频作为附件展示在文章下方；不提供富文本排版、转码或 Markdown 渲染。
- 以年/月和类目浏览归档；媒体库管理与原文件下载。
- 后台配置类目、顶部菜单名称/顺序/目标、站点名称、副标题及主题/背景颜色。
- 删除类目不删除文章；正在被文章引用的附件不能直接删除。
- 草稿及未发布附件只在后台可见。
- 后台密码修改、退出、数据 ZIP 备份。
- 所有界面、程序和数据库均在本地，无 CDN、云数据库或在线登录依赖。

三、换电脑 / 迁移
1. 保存编辑内容，关闭启动时的黑色窗口。不要在博客运行时直接复制。
2. 复制整个 PortableBlog 文件夹到 U 盘、移动硬盘或另一台电脑。
3. 在另一台 Windows 10/11 64 位电脑上双击“启动博客.bat”。
路径和盘符可以改变，不需要安装 Python、数据库或下载依赖。
程序仅监听 127.0.0.1，不向局域网或公网发布。
请勿让两台电脑同时通过共享盘使用同一份 data 文件夹。

四、数据与备份
程序会自动在本目录创建 data 文件夹：
  data\blog.sqlite3   文章、类目、菜单、界面设置和密码校验信息
  data\media\        图片、视频等原文件
runtime 为自带的官方 Python 运行环境。不要删除。
后台顶部“导出数据备份”会生成一致的数据库快照，并包含媒体文件。
此备份只含数据，不含程序与 runtime；完整迁移请复制整个博客目录。
恢复备份：关闭程序，先备份当前 data，然后将当前 data 移到别处，
把备份 ZIP 内的 data 文件夹解压到博客根目录，再启动。
备份创建期间媒体写入会等待，视频很多时备份可能较慢。
数据库与媒体文件未加密。后台密码不能防止拥有文件访问权限的人读取数据。
请勿丢失密码；本版本未提供自动密码找回。

五、故障处理
- 端口占用：先关闭之前的博客窗口，不能同时重复启动。
  如确需改端口，可在命令提示符中运行：
    set BLOG_PORT=8766
    Start-Blog.bat
  浏览器使用启动窗口显示的地址。
- 保存失败：检查剩余磁盘空间及文件夹写入权限。
- 视频无法播放：浏览器支持与视频编码有关，推荐 MP4（H.264 视频/AAC 音频）；
  MOV 等文件可以保存和下载，但不保证浏览器直接播放。可下载后用本地播放器打开。
- 如 Windows 安全软件询问，请核实文件来源后按你自己的设备策略处理。
- 若缺失 DLL 或启动失败，请保留窗口中的报错用于排查；Windows 启动仍需在你的电脑验证。
